How to use this calculator

Enter the requested values, review any options that affect the calculation, and select Calculate. The main answer appears beside the form, with supporting details below it.

How the calculation works

Percentage difference = |A − B| ÷ ((|A| + |B|) ÷ 2) × 100.

Example

The percentage difference between 80 and 100 is 22.22%.

Frequently asked questions

How is this different from percentage change?

Percentage change uses a defined starting value. Percentage difference treats both values equally.
